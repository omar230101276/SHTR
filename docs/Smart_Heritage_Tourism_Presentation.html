Motivation & Objectives
The Tourism Constraint Challenge

The Problem Space

  • Information Overload: Visitors in Cairo & Giza face hundreds of attractions across 5,000+ years of history.
  • Conflicting Constraints: Visitors operate under strict budgets, limited travel hours, mobility needs, and operating windows.
  • Search Engine Gaps: Standard search tools fail to enforce hard constraints alongside personalized tag similarity.

SHTR Project Objective

  • Constraint Satisfaction Engine: Hard boolean filters guarantee zero violations for budget, hours, location, and accessibility.
  • Content-Based Matching: TF-IDF Vectorization & Cosine Similarity match user interest keywords with attraction tags.
  • Category Diversity: Category deduplication ensures top 3 recommendations span distinct heritage domains.
  • Cold-Start Baseline: Popularity-ranked baseline model handles queries without specified tags.

AI Architecture
Dual-Layer Recommendation System

Layer 1: Hard Constraint Engine (CSP)

  • Pre-Scoring Filtering: Evaluates boolean rules before TF-IDF vectorization to eliminate invalid candidates.
  • Location Match: Strictly filters Cairo vs Giza locations.
  • Budget Cap: Enforces cost level threshold (Low: 1, Medium: 2, High: 3).
  • Time & Period: Enforces visit duration <= max hours and operational period.

Layer 2: TF-IDF + Cosine Similarity

  • Vector Space Model: Transforms interest tags and attraction keywords into sparse TF-IDF feature vectors.
  • Cosine Similarity Scoring: Measures cosine angle S ∈ [0, 1] between user query and item vectors.
  • Diversity Deduplication: Selects Top 3 recommendations from unique categories.
  • Baseline Fallback: Seamless fallback to popularity model when no tags are checked.

Mathematical Formulation
AI Formulas & Scoring Mechanics
1. TF-IDF Term Weighting Formula
TF-IDF(t, d, D) = TF(t, d) × log( N / |{d ∈ D : t ∈ d}| )
2. Cosine Similarity Vector Angle Formula
CosineSimilarity(v_user, v_item) = ( v_user · v_item ) / ( ||v_user|| × ||v_item|| )
